# '검색뉴스' 신문사 스타일 테마 적용 가이드

Blogger는 완전 커스텀 XML 테마를 올리는 방식도 있지만, 유지보수가 어렵고
Blogger 업데이트 때마다 깨지기 쉽습니다. 대신 **반응형 기본 테마(Contempo 추천) +
커스텀 CSS**로 신문사 느낌을 내는 방법을 안내합니다. 애드센스 심사에도
"반응형, 모바일 친화적, 탐색 쉬움" 조건에 더 유리합니다.

## 1. 기본 테마 선택
1. Blogger 관리 화면 → **테마**
2. "Contempo" (또는 Notable, Soho 중 택1) 선택 → 적용
3. 테마 미리보기에서 로고 영역, 메뉴 영역 위치 확인

## 2. 블로그 제목/부제 설정
- 설정 → 기본 → 제목: `검색뉴스`
- 설명(부제): `오늘의 질문, 오늘의 해법`

## 3. 카테고리 내비게이션 메뉴 만들기
1. 레이아웃 → 상단 메뉴(또는 "페이지 목록") 가젯 추가
2. `config/topics.json`의 8개 카테고리를 라벨 검색 링크로 등록
   - 예: `생활정보` → URL `/search/label/생활정보`
   - 예: `IT/디지털` → URL `/search/label/IT%2F디지털`
3. 게시물 발행 시 자동으로 붙는 라벨(labels)과 메뉴 링크가 일치해야
   클릭 시 해당 카테고리 글만 모아서 보여줍니다.

## 4. 커스텀 CSS 적용
테마 → 맞춤설정 → 고급 → **CSS 추가**에 아래 내용을 붙여넣으세요.
(테마마다 클래스명이 조금 다를 수 있어, 적용 후 화면을 보며 세부 색상/간격만
미세 조정하면 됩니다.)

```css
/* 신문 마스트헤드 느낌의 헤더 */
.Header .title, .Header h1 {
  font-family: "Noto Serif KR", "Georgia", serif !important;
  font-weight: 900 !important;
  letter-spacing: -1px;
  text-align: center;
}
.Header h1 a {
  color: #111111 !important;
}
.Header .description {
  text-align: center;
  font-style: italic;
  color: #555555;
  border-top: 3px double #111111;
  border-bottom: 1px solid #111111;
  padding: 6px 0;
  margin-top: 6px;
}

/* 본문 제목: 신문 헤드라인 스타일 */
.post-title, h3.post-title {
  font-family: "Noto Serif KR", serif !important;
  font-weight: 800;
  line-height: 1.35;
}

/* 카테고리 라벨을 신문 섹션 태그처럼 */
.post-labels a {
  background: #c0392b;
  color: #fff !important;
  padding: 2px 8px;
  border-radius: 2px;
  font-size: 12px;
  text-decoration: none;
  margin-right: 4px;
}

/* 날짜 헤더를 신문 날짜 라인처럼 */
.date-header {
  border-bottom: 2px solid #111;
  font-weight: bold;
  text-transform: uppercase;
  letter-spacing: 1px;
}

/* 가독성을 위한 본문 폭 제한 */
.post-body {
  font-size: 17px;
  line-height: 1.8;
  max-width: 760px;
}
```

## 5. 구글 폰트 추가 (선택)
테마 → 맞춤설정 → 고급 → CSS 추가 맨 위에 다음을 추가하면 명조체 느낌을 낼 수 있습니다.

```css
@import url('https://fonts.googleapis.com/css2?family=Noto+Serif+KR:wght@400;700;900&display=swap');
```

## 6. 사이드바 구성
레이아웃에서 다음 가젯을 사이드바에 추가하면 신문 느낌이 강화됩니다.
- 인기 게시물 (Popular Posts)
- 라벨(카테고리) 목록
- 보관함(Blog Archive)

## 7. 애드센스 광고 단위 배치 (승인 후)
승인 전에는 광고 코드를 넣지 않아도 되며, 승인 후 다음 위치를 권장합니다.
- 본문 상단 (제목 아래)
- 본문 중간 (자동 삽입 광고 활용 가능)
- 사이드바 상단

과도한 광고 배치는 오히려 승인 거절/정책 위반 사유가 되니, 처음에는
본문 내 1~2개로 시작하세요.
