# '라하뉴스' 신문사 스타일 테마 가이드

ardentnews.co.kr(국내 인터넷 신문사)의 구조를 참고해 Blogger 위에 신문사 느낌의
레이아웃을 구현했습니다. 이 문서는 실제로 적용된 설정을 기록해 둔 것이며,
테마를 초기화하거나 새 블로그에 동일한 디자인을 다시 적용할 때 참고하세요.

## 적용된 구성 요소

### 1. 테마
- **Contempo Light** 사용 (Blogger 테마 갤러리에서 선택)
- ⚠️ "Simple", "Notable" 등 구형/경량 테마는 이 블로그 설정과 호환성 문제로
  글 제목이 아예 렌더링되지 않는 버그가 있었습니다. 테마를 바꿀 때는 반드시
  변경 후 글 제목이 정상적으로 보이는지 확인하세요.

### 2. 카테고리 내비게이션
- 레이아웃 → "페이지 목록(상단)" 가젯(페이지 가젯)을 사용
- 실제 "페이지"가 아니라 각 카테고리의 라벨 검색 URL을 커스텀 링크로 등록:
  - 생활정보 → `/search/label/생활정보`
  - IT/디지털 → `/search/label/IT%2F디지털` (슬래시는 %2F로 인코딩)
  - 이런 식으로 8개 카테고리 전부 등록
- 추가로 소개/문의/개인정보처리방침 페이지 링크도 같은 메뉴에 포함

### 3. 언어 선택 (ardentnews의 국기 아이콘 메뉴에 대응)
- 레이아웃 → 사이드바(상단) → 가젯 추가 → "번역" 위젯 추가
- 스타일: "드롭다운만" 선택, 제목은 비워둠
- 실제로는 화면 왼쪽 상단 ☰(햄버거) 메뉴를 열면 "언어 선택" 드롭다운으로 노출됨
  (Contempo 테마는 모바일 우선 레이아웃이라 사이드바 위젯이 햄버거 메뉴 안에 들어감)

### 4. 커스텀 디자인 (테마 → HTML 편집)
Blogger 테마 커스터마이저의 "CSS 추가" UI는 매우 불안정해서(드롭다운이
제대로 열리지 않는 버그), **테마 → 추가 작업(⋮) → HTML 편집**으로 들어가
`]]></b:skin>` 바로 앞에 커스텀 CSS를 직접 삽입하는 방식을 사용했습니다.
새로 CSS를 추가/수정할 때도 이 방법을 권장합니다.

적용된 CSS 핵심 내용:
- `#header`: 남색(#0d2c6b) 마스트헤드, 흰색 굵은 로고
- `.overflowable-container` / `ul.tabs li.overflowable-item a`: 남색 배경의
  흰색 카테고리 탭 메뉴
- `.post-title`: 남색 굵은 헤드라인
- `.post-labels a`, `.label-name`: 빨간색 라벨 배지
- `.post-body`: 가독성 좋은 본문 폰트 크기/줄간격
- Noto Sans KR 구글 폰트 적용

### 5. 기자 바이라인 & 이미지
- `scripts/common.py`의 `build_byline_html()` / `pick_reporter()`가
  `[라하뉴스] {기자명} 기자 | {이메일}` 형식의 바이라인을 본문 맨 위에 삽입
- `scripts/generate_images.py`가 Pollinations.ai(무료)로 기사당 이미지
  3~5장을 생성해 `<h2>` 소제목 사이사이에 배치

### 6. 광고 (구글 애드센스 + 기타)
- Blogger는 기본적으로 사이드바에 "애드센스" 가젯 슬롯을 2개 미리 만들어 둡니다
  (레이아웃 페이지의 "광고" 섹션). 애드센스 승인 전에는 비활성 상태로 둡니다.
- 승인 후: 레이아웃 → 광고 섹션의 "애드센스" 가젯을 수정 → 광고 단위 연결
- ardentnews처럼 Taboola 같은 콘텐츠 추천 광고를 추가하려면, 별도의
  HTML/자바스크립트 가젯을 본문 하단(바닥글 위)에 추가하고 해당 서비스에서
  발급받은 스크립트를 붙여넣으면 됩니다(가입/승인 절차는 해당 서비스에서 직접 진행).

## 브랜드/도메인 변경 시 체크리스트
사이트명이나 기자 이메일 도메인을 다시 바꾸고 싶다면:
1. `config/site.json`의 `site_name`, `reporters[].email` 수정
2. Blogger 설정 → "제목" 필드를 블로그 관리 화면에서 직접 수정 (API로 변경 불가)
3. `python scripts/backfill_byline.py` 실행 → 기존 글의 바이라인을 새 값으로 일괄 교체
   (내부적으로 기존 바이라인을 지우고 다시 생성하므로 몇 번을 실행해도 안전합니다)

## 참고: Blogger 테마 편집기 UI 관련 팁
- 레이아웃/테마 페이지는 내부적으로 iframe과 Material 커스텀 드롭다운으로
  구성되어 있어, 화면을 보고 좌표를 클릭하는 자동화가 잘 안 맞을 때가 많습니다.
  문제가 생기면 브라우저 콘솔에서 `document.querySelector`로 요소를 직접 찾아
  `.click()`하거나, 가능하면 **HTML 편집**으로 우회하는 것이 가장 안정적입니다.

## ⚠️ 중요 사고 기록: 글 제목이 전부 사라졌던 사건 (2026-10-17)

### 증상
모든 글의 제목이 사라지고(`headline: "제목 없음"`), 라벨도 전부 비어있었음.
테마/CSS/위젯 문제처럼 보였지만 실제로는 **Blogger API 데이터 손상**이었음.

### 근본 원인
`backfill_images.py`, `backfill_byline.py` 같은 소급 적용 스크립트가
`service.posts().update(body={"content": ...})` 형태로 **content 필드만** 보내고
title/labels를 빼먹었음. Blogger API의 `posts().update()`는 **전체 교체(PUT) 방식**이라
body에 없는 필드는 지워짐 → 모든 글의 title/labels가 통째로 사라짐.

**교훈: Blogger API로 글을 update()할 때는 항상 title/labels/content를 전부 포함해서
보내야 한다.** (읽어온 기존 값을 그대로 다시 넣더라도 반드시 포함할 것)

### 복구 방법
GitHub Secrets는 쓰기 전용이라 기존 refresh token/API 키를 다시 볼 수 없었음.
`scripts/get_refresh_token.py`로 새 refresh token을 발급받고,
`scripts/repair_missing_titles.py`로 각 글의 본문(h2 소제목, 키워드 빈도)만 보고
제목과 카테고리를 추론해서 복구함 (Gemini 등 외부 API 호출 없이 본문 정보만 사용).

### 별개로 발견된 버그: "추천 게시물(FeaturedPost)" 위젯이 메인 페이지의 글 목록을 전부 숨김
홈페이지에서 `Blog1` 위젯의 `.blog-posts` 영역이 완전히 비어 있었음(글이 0개).
`FeaturedPost1` 위젯을 끄니 즉시 정상적으로 글이 표시됨.
→ **FeaturedPost 위젯과 Blog1(기본 글 목록) 위젯을 같은 페이지에 함께 쓰면
Blog1이 깨지는 버그가 있음.** ardentnews 스타일의 "추천 기사" 섹션을 다시 넣고
싶다면 FeaturedPost 위젯 대신 다른 방식(예: 라벨 검색 기반 수동 HTML 가젯)을
검토할 것.
