파란 화면에서 정보를 읽는 법

블루스크린에는 원인을 좁힐 단서가 들어 있습니다. Microsoft 안내에 따르면 화면 아래쪽에 PAGE_FAULT_IN_NONPAGED_AREA, MEMORY_MANAGEMENT 같은 정지 코드가 표시되고, 경우에 따라 문제가 생겼을 때 실행 중이던 코드의 모듈 이름도 함께 나옵니다. 화면 색과 문구는 윈도우 버전에 따라 다르며, Windows 11 24H2 이후는 23H2 이하와 모양이 다르게 안내됩니다. 재부팅하면 사라지므로 휴대폰으로 화면을 찍어 두는 편이 안전합니다.

한 번 나타나고 다시 안 생긴다면 일시적인 충돌이었을 가능성이 있습니다. Microsoft도 재시작만으로 해결되는 경우가 많다고 설명하며, 같은 정지 코드가 반복될 때 본격적으로 점검하라고 안내합니다. 화면이 검거나 비어 있고 정지 코드가 없다면 블루스크린이 아니라 별도의 화면 출력 문제로 분류됩니다.

부팅이 반복 실패할 때의 복구 경로

윈도우로 진입하지 못하는 상황에서는 안전 모드가 출발점입니다. 안전 모드는 제한된 파일과 드라이버만으로 윈도우를 시작하는 기능으로, Windows 복구 환경에서 '문제 해결 > 고급 옵션 > 시작 설정 > 다시 시작'을 거쳐 진입합니다. 다시 시작하면 안전 모드, 네트워킹 사용 안전 모드, 명령 프롬프트 사용 안전 모드 중 고를 수 있고, 평소처럼 재부팅하면 일반 모드로 돌아옵니다. 메뉴 이름은 버전별로 조금 다를 수 있습니다.

안전 모드나 정상 진입이 가능하다면 Microsoft가 제시하는 기본 점검을 차례로 해 보세요.

  1. 새로 단 하드웨어 제거: 오류 직전에 메모리, 저장 장치, USB 장치 등을 추가했다면 빼고 재부팅합니다.
  2. 장치 관리자 확인: 시작 버튼 우클릭 > 장치 관리자에서 느낌표가 붙은 장치를 찾아 드라이버 업데이트를 시도하고, 안 되면 장치를 사용 안 함 또는 제거합니다.
  3. 저장 공간 여유 확보: 시스템 드라이브의 약 10~15%는 비워 두라고 안내합니다.
  4. 윈도우 업데이트: Windows 11은 설정 > Windows 업데이트에서 확인합니다.
  5. 복원: 위 방법이 통하지 않으면 시스템 복원 지점 등 복구 옵션을 이용합니다. 복원은 개인 파일은 건드리지 않지만 이후 설치한 프로그램은 사라질 수 있습니다.

메모리 검사와 덤프 파일, 서비스센터에 가져갈 정보

램 이상이 의심되면 Win+R에서 mdsched를 실행해 Windows 메모리 진단을 쓸 수 있습니다. 재시작 후 부팅 전에 검사가 진행되고, 로그인하면 결과가 알림으로 표시됩니다. 이 도구가 문제를 찾지 못했다고 램이 완전히 정상이라는 보장은 없으니, 램이 2개 이상이라면 하나씩 꽂아 번갈아 테스트하는 방법이 보완책이 됩니다.

블루스크린이 생길 때 윈도우는 작은 메모리 덤프(미니덤프)를 남길 수 있습니다. Microsoft 기술 문서에 따르면 기본 저장 위치는 %SystemRoot%\Minidump이고 크기는 보통 256KB 정도이며, 설정을 바꾼 뒤에는 그 이후에 발생한 충돌부터 기록됩니다. 같은 문서는 오류의 상당 부분이 불량 드라이버에서 비롯된다고 설명합니다. 분석에는 무료 도구인 WinDbg를 쓰지만 일반 사용자에게는 어렵습니다.

서비스 접수 전에는 정지 코드와 발생 시점, 직전에 설치한 것을 메모해 두면 진단이 빨라집니다.

정기적인 예방 점검도 도움이 됩니다. 그래픽 드라이버를 업데이트할 때는 제조사 공식 사이트에서 받은 설치 파일을 쓰고, 설치 직후 이상이 생기면 이전 버전으로 되돌릴 수 있도록 장치 관리자의 드라이버 롤백 기능을 확인해 둡니다. 윈도우 업데이트 직후 문제가 시작됐다면 업데이트 기록을 확인해 어떤 업데이트인지 메모하세요. 오버클럭이나 XMP 같은 메모리 설정을 켜 둔 경우에는 기본값으로 돌려 보면 원인이 가려지는 경우가 있습니다. 노트북은 환기구에 먼지가 쌓여 발열이 커지기도 하므로 사용 환경과 팬 소음 변화도 함께 살펴보세요. 중요한 데이터는 외장 저장 장치나 클라우드에 따로 백업해 두는 것이 무엇보다 안전합니다.
