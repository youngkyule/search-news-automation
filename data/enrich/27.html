PC 문제인지 공유기 문제인지 먼저 가르는 방법

설정을 이것저것 바꾸기 전에 원인이 PC 쪽인지 네트워크 쪽인지부터 나누면 시간을 아낄 수 있습니다. Microsoft 지원 문서가 안내하는 확인 순서는 다음과 같습니다.

  1. 다른 기기로 같은 와이파이에 접속해 보기 - 휴대폰도 접속이 안 되면 공유기나 인터넷 회선 쪽 문제일 가능성이 큽니다.
  2. 2.4GHz와 5GHz 중 다른 쪽 선택 - 두 이름이 모두 보이면 반대쪽에 연결해 봅니다.
  3. 모뎀과 공유기 전원 껐다 켜기 - 공유기를 뽑고 모뎀도 뽑은 뒤 약 30초 기다렸다가 모뎀을 먼저, 불빛 깜빡임이 멈춘 뒤 공유기를 연결하고 몇 분 기다립니다. 모뎀 겸용 공유기라면 그 장비 하나만 재부팅합니다.
  4. 기본 게이트웨이로 핑 보내기 - 관리자 권한 명령 프롬프트에서 ipconfig를 입력해 '기본 게이트웨이' 주소를 확인하고 ping 뒤에 그 주소를 입력합니다. 응답이 오면 공유기까지는 정상이므로 모뎀이나 통신사 쪽을 의심하고, 응답이 없다면 모뎀에 랜선을 직접 연결해 되는지 보면서 공유기 문제인지 가립니다.

이 과정에서 공유기 쪽 문제로 좁혀졌다면 PC 설정을 건드릴 필요가 없습니다. 공유기 펌웨어 업데이트나 통신사 장애 여부 확인으로 넘어가세요.

본문에서 다루지 않은 PC 쪽 점검 항목

Winsock과 IP 초기화 명령 외에도 Microsoft 문서에는 함께 쓰라고 소개된 명령이 있습니다. 순서는 netsh winsock reset, netsh int ip reset, ipconfig /release, ipconfig /renew, ipconfig /flushdns이며, 관리자 권한 명령 프롬프트에서 입력합니다. 앞의 두 줄만 실행하고 끝냈다면 release와 renew까지 이어서 해 주면 IP를 새로 받아 오는 단계가 빠지지 않습니다.

  • 절전 설정: 장치 관리자의 네트워크 어댑터에서 사용 중인 무선 어댑터를 열고 '전원 관리' 탭의 '전원을 절약하기 위해 컴퓨터가 이 장치를 끌 수 있음' 체크를 해제합니다. 와이파이가 자주 끊길 때 확인해 볼 항목입니다.
  • 와이파이 항목 자체가 없을 때: 노트북의 물리 스위치나 기능키를 확인하고, 장치 관리자에서 어댑터가 '사용 안 함' 상태인지 봅니다. Win+R로 services.msc를 열어 WLAN AutoConfig 서비스를 다시 시작하는 방법도 안내되어 있습니다.
  • 연결은 됐는데 인터넷이 안 될 때: 설정의 프록시에 수동 프록시가 켜져 있는지 확인합니다. ipconfig 결과의 IP가 169.254로 시작하면 공유기에서 주소를 받지 못한 상태이니 공유기의 DHCP 설정을 확인해야 합니다.
  • 비밀번호 오류가 계속 날 때: 비밀번호를 다시 확인하고, 저장된 네트워크를 '알려진 네트워크 관리'에서 삭제(잊기)한 뒤 다시 접속해 봅니다.

마지막 수단인 네트워크 초기화의 영향

모든 방법이 소용없을 때 쓰는 것이 '네트워크 초기화'입니다. Windows 11에서는 설정 > 네트워크 및 인터넷 > 고급 네트워크 설정 > 네트워크 초기화에서 실행하고, Windows 10은 상태 화면에서 같은 메뉴로 들어갑니다. 설치된 네트워크 어댑터를 제거한 뒤 재시작 때 기본값으로 다시 설치하는 방식이라 아래 같은 부작용이 있습니다.

  • VPN 클라이언트나 Hyper-V 가상 스위치를 다시 설정해야 할 수 있습니다.
  • 알려진 네트워크가 '공용' 프로필로 바뀔 수 있어, 집 네트워크는 필요하면 '개인'으로 되돌려야 합니다.
  • 저장된 와이파이 비밀번호를 다시 입력해야 할 수 있으니 미리 공유기 스티커 등으로 확인해 두세요.

드라이버를 지우고 다시 설치해야 할 때는 먼저 PC 제조사 사이트에서 무선 드라이버를 내려받아 저장해 두세요. 삭제 후 윈도우가 자동 재설치하지 않으면 그 파일로 직접 설치하는 순서가 Microsoft 문서에도 소개되어 있습니다. 인터넷이 안 되는 상태에서 드라이버를 받으려면 스마트폰 테더링이 필요합니다.

마지막으로 증상별 판단 기준을 정리합니다. 와이파이 목록 자체가 비어 있다면 어댑터나 스위치, 서비스 문제를 먼저 의심합니다. 목록은 보이는데 접속 단계에서 막힌다면 비밀번호, 보안 방식, 저장된 네트워크 정보 문제입니다. 접속은 되지만 인터넷만 안 된다면 IP 주소, DNS, 프록시, 공유기 회선 순으로 봅니다. 증상이 이 중 어디에 해당하는지 먼저 정하면 불필요한 초기화를 줄일 수 있고, 한 가지를 바꿀 때마다 접속을 다시 시험해 어느 단계에서 풀렸는지 기록해 두면 같은 문제가 재발했을 때도 빠르게 대응할 수 있습니다. 통신사 장애나 공유기 고장이 의심되면 통신사 고객센터에 회선 점검을 요청하세요.
